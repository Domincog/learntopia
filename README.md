# Learntopia

**Small steps to big ideas.** Learntopia is a free, open-source website for learning math, logic, computer science, science, history, geography, health, psychology and money *by doing*: short interactive lessons, instant explanations, and spaced review that brings each idea back just before you would forget it.

- **Lessons that teach, then ask** — each idea is shown on a short screen with a picture or a worked example, then used at once: drag points, balance scales, run simulations, order code
- **Built on learning research** — retrieval practice, spacing, interleaving, explanatory feedback, calibration ([the evidence](docs/LEARNING-SCIENCE.md))
- **Maps, timelines and photographs** — an interactive world map drawn from public-domain data, and freely licensed pictures that carry their credit ([maps](docs/MAPS.md), [images](docs/IMAGES.md), [picture credits](content/media/CREDITS.md))
- **The human body** — an original, interactive anatomy diagram drawn in code (systems, organs, the heart, the airways, the skin and a cell), and real micrographs, scans and medical illustrations wherever the real thing teaches better ([guide](docs/BODY.md))
- **Health and money courses written with care** — sourced to current guidance, each checked by a second reviewer, never asking for your own health or financial data; general education, not medical or financial advice ([how they are written](docs/HEALTH.md))
- **Spaced review** with an open memory model (FSRS) and regenerated problems, so you practise the skill rather than recall an answer
- **Private by construction** — no accounts, no tracking, no cookies, no server; progress lives in the learner's browser and can be exported
- **Works offline** and installs as an app (PWA)
- **No build step, no dependencies** — plain HTML, CSS and JavaScript modules; a lesson is one small file
- **Fits the screen it is on** — one column on a phone, question and interactive side by side on a laptop, larger on a big monitor
- **Accessible** — keyboard-operable interactives, screen-reader labels, dark mode, adjustable text size, reduced motion

The mascot is Lem, a ring-tailed lemur who cheers when you get something right and is entirely unbothered when you do not.

## Run it locally

You need [Node.js](https://nodejs.org) 18 or newer (only to serve the files and run the checks; the site itself has no dependencies).

```bash
node tools/serve.mjs
```

Then open <http://localhost:8080>. Any static file server works as well. (Opening `index.html` directly from disk does not, because browsers refuse to load JavaScript modules from `file://`.)

## Deploy to Cloudflare Pages

The repository root **is** the website. There is nothing to build.

**Option A — connect the Git repository (recommended).** In the Cloudflare dashboard go to *Workers & Pages → Create → Pages → Connect to Git* and choose the repository. Use these build settings:

| Setting | Value |
|---------|-------|
| Framework preset | None |
| Build command | *(leave empty)* |
| Build output directory | `/` |

Every push then deploys automatically, and nothing has to be downloaded or uploaded by hand.

**Option B — command line.** From a clone of the repository, or from an unpacked "Source code" zip of a release:

```bash
npx wrangler pages deploy . --project-name learntopia
```

Dragging the folder or a zip into the dashboard (*Upload assets*) does **not** work for this project: that route accepts at most 1,000 files, and the site has more (every lesson is its own file, plus about 350 picture files). Git and Wrangler allow 20,000.

The included [`_headers`](_headers) file sets a strict Content-Security-Policy and sensible caching on Cloudflare Pages. Routing uses the URL hash (`#/courses`), so no redirect rules are needed and the site also works unchanged on GitHub Pages, Netlify or any other static host.

**Custom domain.** The reference site runs at <https://learntopia.org>. That address appears in three places: `siteUrl` in [`src/config.js`](src/config.js), the canonical and Open Graph tags in [`index.html`](index.html), and [`robots.txt`](robots.txt) with [`sitemap.xml`](sitemap.xml). Change them if you host a copy somewhere else, then attach the domain to the Pages project under *Custom domains*.

If you publish the source in a public repository, put its address in `repoUrl` in [`src/config.js`](src/config.js). The app then shows a "Source code" link and a "Suggest an edit" link at the end of every lesson that opens that lesson's file in the repository's web editor. The same file is where you rename the site.

## Write a lesson

Lessons are plain JavaScript objects. Here is a complete question:

```js
{
  id: 'solve-add',
  type: 'numeric',
  review: true,                         // bring it back later, spaced out
  gen: (rng) => {                       // fresh numbers every time
    const x = rng.int(3, 19);
    const a = rng.int(2, 15);
    return {
      text: r`Solve for $x$: $$ x + ${a} = ${x + a} $$`,
      answer: x,
      wrong: [[x + a + a, `You added ${a}. To undo "plus ${a}", subtract it.`]],
      hints: [`What undoes "plus ${a}"?`],
      explain: r`Subtract ${a} from both sides: $x = ${x}$.`,
    };
  },
}
```

- **[docs/AUTHORING.md](docs/AUTHORING.md)** — the lesson recipe, all fourteen step types, formatting, generated problems, review steps
- **[docs/WIDGETS.md](docs/WIDGETS.md)** — the built-in interactive figures and how to write your own
- **[docs/CODE-STEPS.md](docs/CODE-STEPS.md)** — runnable code steps and the mini-Python interpreter

Preview any lesson without affecting saved progress at `#/dev/lesson?course=<id>&lesson=<id>`; `#/dev` lists all author tools (step sampler, widget gallery, time travel for testing spaced review).

## Check your work

```bash
npm test
```

Unit tests for the scheduler, progress rules, math engine, markdown renderer and interpreter.

```bash
npm run validate
```

Checks every lesson: structure, generated variants across many random seeds, formulas that compile, widget references, and a list of quality warnings.

```bash
npm run smoke
```

Plays every lesson in a headless browser at laptop and phone sizes and fails if anything throws, overflows the screen sideways, or if a step's own solution is not accepted by its own check. It also reports which steps need scrolling on a laptop. Needs Playwright:

```bash
npm install --no-save playwright && npx playwright install chromium
```

```bash
npm run a11y
```

Runs the axe-core accessibility rules (WCAG 2.1 A and AA) on the main pages and on every step of every lesson, before and after it is answered. Add `--dark` for the dark theme. Needs Playwright and axe-core:

```bash
npm install --no-save playwright axe-core
```

After adding or removing files, refresh the offline file list and the widget gallery index:

```bash
npm run precache
```

## Design principles

1. **The learner's time is the scarce resource.** Every screen should earn its place.
2. **Evidence over fashion.** Features exist because research supports them, and [we cite it](docs/LEARNING-SCIENCE.md).
3. **No dark patterns.** No guilt, no artificial scarcity, no engagement tricks. Streaks have rest days. Nothing is for sale.
4. **Local first.** No backend to run, pay for or trust.
5. **Readable code.** No framework and no build means anyone can open a file and see how it works.

## Support the project

Learntopia is free for everyone, with no ads, no tracking and nothing locked away, and it will stay that way. It is an independent project, so its costs are paid out of pocket and by people who choose to chip in:

- **Writing and checking courses.** Lessons are drafted, cross-checked and tested with the help of AI tools that are paid for by use, and every course is reviewed independently afterwards. This is most of the bill: about $200 a month at present.
- **Keeping the site online.** Domain, hosting and bandwidth.
- **Next goal: optional accounts.** A small server so that progress can follow a learner between devices. The site will always work without signing up.

If Learntopia is useful to you, you can help at **<https://ko-fi.com/domlincog>**, once or monthly. To put the numbers in proportion: 40 people giving $5 a month would cover the current costs. Supporters get nothing extra, because nothing is held back from anyone.

Help that costs nothing is just as welcome: tell a friend or a teacher, report a mistake, or write a lesson (see below).

In the app this lives on one page (`#/support`), linked quietly from the sidebar, Settings and "How it works", plus a single short note when a learner finishes a whole course, which they can switch off. There are no pop-ups or banners. The address, the service name and the monthly figure are set in `support` in [`src/config.js`](src/config.js); if you run your own copy, point it at your own page or leave `url` empty and every trace disappears.
